# Magnitude-First Temporal Model (MFTM)

**Status: research protocol and mathematical implementation in progress. No empirical or physical-theory findings are claimed yet.**

MFTM investigates what can and cannot be inferred when temporal observations are represented first as non-negative pairwise separations:

\[
D_{ij}=|t_i-t_j|.
\]

The project separates a representational choice from claims about the ontology of time or the laws of physics. Its purpose is to make mathematical claims explicit, test code reproducibly, review relevant prior work, and define falsification criteria before interpreting results.

## Core questions

1. Under what conditions can a set of pairwise temporal magnitudes reconstruct one-dimensional coordinates?
2. What information is lost when signed differences and an origin are removed?
3. Which properties are identifiable from magnitude-only observations, and which are not?
4. How does this representation relate to coordinate time, proper time, aging, relativistic spacetime, and quantum formalisms?
5. Which claims are mathematical theorems, implementation checks, empirical findings, interpretations, or speculation?

## Important boundaries

- **Definition is not discovery.** The identity \(D_{ij}=|t_i-t_j|\) defines a representation; by itself it is not evidence for a new physical theory.
- **Reconstruction has symmetries.** Exact one-dimensional pairwise distances determine coordinates only up to translation and reflection, subject to the data being consistent with a line embedding.
- **A chosen origin is not a privileged present.** Setting one reconstructed coordinate to zero is a coordinate convention, not evidence that “now” is physically preferred.
- **Coordinate-time separation is not generally proper time.** Relativistic proper time depends on a worldline and spacetime geometry; it must not be conflated with a generic difference between coordinate labels.
- **A passing unit test validates implementation behavior, not ontology.** Physical claims require separate arguments and evidence.
- **Quantum comparisons are not derivations.** Similar vocabulary or mathematical form is not sufficient to establish a connection.

## Reproducibility principles

1. Record assumptions, random seeds, software versions, and exact commands.
2. Keep generated results separate from proposed hypotheses.
3. Report negative and inconclusive results as well as positive results.
4. Do not silently change hypotheses after seeing outcomes; document revisions and preserve earlier versions.
5. Do not label synthetic tests as empirical validation.
6. Distinguish numerical tolerance failures from conceptual counterexamples.
7. Cite primary sources for literature claims and record the search date.

## Initial mathematical target

For a symmetric matrix of squared dissimilarities \(D^{(2)}\), classical multidimensional scaling forms

\[
B=-\frac12 JD^{(2)}J, \qquad J=I-\frac1n\mathbf{1}\mathbf{1}^{\mathsf T}.
\]

For exact Euclidean distances among points on a line, the centered Gram matrix should be positive semidefinite and have rank at most one (up to numerical tolerance). This is a useful implementation and consistency target, not a complete test of any broader physical interpretation.
