# Formal Mathematical Specification

## 1. Domain and definitions

Let \(E=\{e_1,\ldots,e_n\}\) be a finite set of event labels, each assigned a real-valued coordinate \(t_i\in\mathbb R\) in a conventional one-dimensional time coordinate. Define

\[
D:E\times E\to[0,\infty),\qquad D(e_i,e_j)=|t_i-t_j|.
\]

The induced matrix \(D=[D_{ij}]\) is symmetric, nonnegative and has a zero diagonal. It obeys the triangle inequality. Thus it is a **pseudometric** on event labels: distinct labels may have identical timestamps and hence zero distance. It is a metric exactly when distinct event labels have distinct coordinates.

For squared dissimilarities \(D^{(2)}\), classical multidimensional scaling (MDS) forms

\[
B=-\frac12 JD^{(2)}J,\qquad J=I-\frac1n\mathbf1\mathbf1^T.
\]

When the distances are generated by points on a Euclidean line, \(B\) is positive semidefinite and has rank at most one, up to numerical tolerance.

## 2. P1 / H1 — distance sufficiency

**Proposition.** An exact, complete, labeled pairwise distance matrix generated by points known to lie on a one-dimensional Euclidean line determines the coordinates uniquely up to translation and reflection.

**Proof sketch.** Classical distance geometry reconstructs the centered Gram matrix \(B\) from the complete squared-distance matrix. For an exact line embedding, \(B=xx^T\) where \(x\) is the centered coordinate vector, so its one-dimensional factorization recovers \(x\) up to sign (with all-zero configurations handled separately). The original coordinates are \(x+c\mathbf1\), where the free constant \(c\) is translation. The sign ambiguity is reflection. For non-degenerate point sets, no additional degrees of freedom remain. This result relies on exact complete distances and the line-embedding assumption; incomplete/noisy data may be non-unique.

## 3. P2 / H2 — orientation non-identifiability

For any constant \(c\), define \(t'_i=c-t_i\). Then

\[
D'_{ij}=|t'_i-t'_j|=|(c-t_i)-(c-t_j)|=|t_j-t_i|=D_{ij}.
\]

Therefore global reflection is unobservable from magnitudes alone. A magnitude-only observation of a pair does not reveal which event is earlier. This is mathematical non-identifiability, not measurement noise.

## 4. P3 / H3 — reference-point sufficiency

For a designated event \(k\), define \(\tau_i=t_i-t_k\). This changes the coordinate origin so that \(\tau_k=0\), while

\[
|\tau_i-\tau_j|=|t_i-t_j|,\qquad |\tau_i|=D_{ik}.
\]

The origin shift adds no direction bit. If only \(D_{ik}\) is supplied, the sign of each \(\tau_i\) relative to the reference is not generally identified from those magnitudes alone. A named “present” is a reference-point convention, not by itself a physically privileged present hypersurface.

## 5. P4 / H4 — minimal orientation recovery

**Proposition.** Suppose a complete exact distance matrix comes from a non-degenerate one-dimensional configuration. Its reconstruction is determined up to translation/reflection. One directed relation between two events at distinct reconstructed positions chooses between the two reflected orientations. Conversely, absent directional external information, reflection invariance prevents a data-only procedure from identifying which global orientation is physically intended.

This assumes event identities and complete distances are available, the directed relation is reliable, and the two events have distinct coordinates. Equal-timestamp events cannot be ordered by coordinate chronology. In noisy/incomplete data, one constraint may not resolve all ambiguities.

## 6. P5 / H9 — higher-dimensional ambiguity and representation

A distance matrix can describe configurations in more than one dimension. Without the prior assumption that the points lie on a line, the matrix does not impose a unique linear chronology. In Euclidean geometry a complete exact distance matrix identifies a configuration only up to Euclidean isometries in its minimal embedding space; it does not select a physically privileged time direction. If the centered Gram matrix has rank greater than one, the exact embedding is not one-dimensional.

## 7. Noise and incomplete observations (H5)

Noise changes the geometry of the observed distance matrix and can lead to violations of triangle inequality or to Gram matrices that are not positive semidefinite/rank one. A rank-one spectral reconstruction can provide an approximation, but no universal monotone relation between noise amplitude and every error metric is presumed: results depend on noise distribution, sampling, coordinate geometry, and estimator. The experiment script records metrics over fixed seeds and noise levels. These synthetic experiments quantify implementation behavior only.

## 8. Relativity boundary (H6)

A coordinate-time difference is not generally the elapsed proper time along a worldline. In flat spacetime for an inertial clock at constant speed \(v\), the special-relativistic example is \(\Delta\tau=\Delta t\sqrt{1-v^2/c^2}\). This code example illustrates a distinction; it is not an MFTM prediction. Any broader claim must specify the events, worldline, metric, frame, observable, and mapping from MFTM quantities to physical quantities. “Present” on one observer's worldline is distinct from a universal present hypersurface.

## 9. Quantum and ontology boundaries (H7, H8, H10)

Relational-clock frameworks and indefinite-causal-order experiments pose specific operational questions about temporal correlations and causal structure. They do not, by themselves, show that ordinary temporal magnitude is ontologically prior to ordering. No new quantum model, novel empirical prediction, or extra mathematical structure is established in this repository. Those hypotheses remain unresolved pending formal derivations and a prior-art audit.
