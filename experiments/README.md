# Experiments

Store each experiment as a separate, versioned specification with:
- question and hypothesis identifier;
- exact procedure and inputs;
- fixed random seed where randomness is used;
- software and hardware versions where relevant;
- expected outputs and evaluation metrics;
- failure criteria and numerical tolerances;
- command used to run it;
- raw outputs and a short interpretation.

Do not add hand-written numbers to the results directory as if they were generated outputs. Do not call synthetic simulations empirical evidence about physical time.
